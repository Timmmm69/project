## Цель

Представлять неподтверждённый provider/status transport outcome как transient API projection без ложного terminal state.

## В scope

- Реализовать только цель и критерии этой карточки.
- Сохранить backend truth, idempotency, transaction и privacy invariants.

## Вне scope

- Реализация соседних карточек без отдельного claim.

- Card-data UI, embedded bank form, автоматические возвраты и другие запрещённые MVP-функции.


## Критерии приёмки

- [ ] `payment_status_unknown` не означает paid/failed и не меняет подтверждённый business state.
- [ ] Новый DB enum не добавлен без отдельного доказанного требования.
- [ ] Status/refresh DTO типизированы и не раскрывают provider details.
- [ ] Unknown запрещает повторную оплату.
- [ ] Есть unit/integration tests для timeout, malformed и unavailable status.
