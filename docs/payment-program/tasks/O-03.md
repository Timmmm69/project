## Цель

Зафиксировать receipt process и ручной refund workflow без добавления автоматических возвратов.

## Источники требований

- `docs/payment-program/sources/payment-ux-contract-v1.md`
- `docs/00-final-mvp-spec-v2.md`

Audit/traceability IDs: `DOC-01`.

## В scope

- Реализовать только цель и критерии этой карточки.
- Сохранить backend truth, idempotency, transaction и privacy invariants.
- Обновить board, evidence и handoff вместе с изменением.

## Вне scope

- Реализация соседних карточек без отдельного claim.
- Production activation или изменение gate verdict.
- Card-data UI, embedded bank form, автоматические возвраты и другие запрещённые MVP-функции.


## Критерии приёмки

- [ ] Определены receipt provider/steps, владелец и evidence.
- [ ] Manual refund policy согласована с public terms.
- [ ] Duplicate/failed/late-success случаи имеют операционный маршрут.
- [ ] Автоматический refund остаётся out of scope.
- [ ] Payment/access state не меняется непроверенной browser action.

## Обязательные проверки

- [ ] Проверка authoritative происхождения evidence.
- [ ] Проверка отсутствия secrets/PII в репозитории.
- [ ] Независимый gate review; mock/assumption не принимается как закрытие.

## Evidence

- WEBPAY отправляет payment confirmation; согласно authoritative МНС плательщик
  НПД отдельно формирует и передаёт чек приложения НПД по каждому расчёту.
- `/service-delivery` разделяет WEBPAY confirmation и чек НПД; не утверждает
  наличие отдельного кассового оборудования.
- `/refunds` фиксирует manual-only workflow, safe intake, review SLA и запрет
  автоматического refund/browser mutation.
- До `DONE`: подтвердить операционную передачу чека НПД, провести refund
  tabletop с кабинетом WEBPAY/МТБанка и independent O-03 review.

## Handoff

Следующее точное действие: проверить формирование/передачу чека НПД и ручной
возврат в реальном кабинете WEBPAY/МТБанка, затем независимое O-03 review.

Нерешённые вопросы должны быть перечислены здесь и в `docs/payment-program/handoff.md`; молчаливые архитектурные, финансовые, security или scope решения запрещены.
