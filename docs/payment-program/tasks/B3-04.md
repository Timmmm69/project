## Критерии приёмки

- [ ] Commercial и затронутый legacy code не сохраняют raw request/response payload.
- [ ] Allowlist исключает PAN/masked PAN/CVV/expiry/3DS/signatures/secrets.
- [ ] Existing stored payload policy и migration/retention определены.
- [ ] Analytics/logging не получают raw provider data.
- [ ] Static/runtime privacy scans покрывают callback/create/status paths.
