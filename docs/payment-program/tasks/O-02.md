## Цель

Определить рабочий support email/hours и действия для pending, duplicate payment и paid_without_access.

## Источники требований

- `docs/payment-program/sources/payment-ux-contract-v1.md`
- `docs/payment-program/sources/payment-core-audit-2026-07-18.md`

Audit/traceability IDs: `STA-07`, `ACC-02`.

## В scope

- Реализовать только цель и критерии этой карточки.
- Сохранить backend truth, idempotency, transaction и privacy invariants.
- Обновить board, evidence и handoff вместе с изменением.

## Вне scope

- Реализация соседних карточек без отдельного claim.
- Production activation или изменение gate verdict.
- Card-data UI, embedded bank form, автоматические возвраты и другие запрещённые MVP-функции.


## Критерии приёмки

- [ ] Support channel протестирован и имеет владельца/SLA.
- [ ] Runbook использует только public order reference и safe DTO.
- [ ] Определены thresholds/escalation для pending/unknown/PWA.
- [ ] Duplicate payment не приводит к automatic refund или второму Access.
- [ ] Недоступный support удерживает production gate закрытым.

## Обязательные проверки

- [ ] Проверка authoritative происхождения evidence.
- [ ] Проверка отсутствия secrets/PII в репозитории.
- [ ] Независимый gate review; mock/assumption не принимается как закрытие.
