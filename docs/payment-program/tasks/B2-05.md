## Критерии приёмки

- [ ] Retry разрешён только из failed/cancelled/expired.
- [ ] Создаётся новая PaymentAttempt в существующем Order.
- [ ] Pending/unknown/PWA не допускают retry.
- [ ] Transition table, service и tests описывают одинаковую семантику.
- [ ] Concurrent retry сохраняет не более одной active attempt.
