## Критерии приёмки

- [ ] `POST /api/commercial/orders` не доверяет email из request body.
- [ ] До verification нельзя узнать Existing Order/Access/Result.
- [ ] После verification используется normalized email из authority.
- [ ] Same-flow replay и concurrent submit не создают второй Order.
- [ ] Unauthorized/expired/cross-scope session получает безопасный отказ.
