## Цель

Обеспечить recoverable creation/finalization provider session при crash или потере ответа без второй active PaymentAttempt.

## Источники требований

- `docs/payment-program/sources/payment-ux-contract-v1.md`
- `docs/payment-program/sources/payment-core-audit-2026-07-18.md`

Audit/traceability IDs: `PAY-04`, `PAY-05`.

## В scope

- Реализовать только цель и критерии этой карточки.
- Сохранить backend truth, idempotency, transaction и privacy invariants.
- Обновить board, evidence и handoff вместе с изменением.

## Вне scope

- Реализация соседних карточек без отдельного claim.
- Production activation или изменение gate verdict.
- Card-data UI, embedded bank form, автоматические возвраты и другие запрещённые MVP-функции.


## Критерии приёмки

- [ ] Локальное состояние различает started/finalized/recoverable session creation.
- [ ] Retry не создаёт вторую active attempt.
- [ ] Existing finalized session повторно открывается безопасно.
- [ ] Неопределённый provider outcome не трактуется как failure или payment proof.
- [ ] Fault-injection tests покрывают crash до/после provider response.

- [ ] `pnpm lint`.
- [ ] `pnpm typecheck`.
- [ ] `pnpm test` плюс targeted unit/integration tests.
- [ ] Релевантный migration/transaction/concurrency smoke.
