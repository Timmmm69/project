- [x] Session scope привязан к точным User/Product/Test/Access.

- [x] Cookie/token lifecycle, hashing, rotation, revocation и concurrency соответствуют bridge decision.
- [x] Generic MVP продолжает использовать legacy plane без смешивания.

## Evidence

- Additive Prisma enums/model/migration:
  `VerifiedStudentSessionSource`,
  `VerifiedStudentSessionRevocationReason`,
  `VerifiedStudentSession` и
  `20260713180000_add_verified_student_session_foundation`.
- Таблица хранит только versioned HMAC digest и exact User/Product/Test/Access
  scope; raw 256-bit token существует только в process memory/cookie.
- `config.ts` реализует exact `off | shadow | enforce`, dedicated key ring,
  active version, minimum 32-byte keys, cross-secret reuse checks и
  production-like placeholder rejection.
- `token.ts` реализует strict versioned opaque token, domain-separated HMAC и
  constant-time digest comparison.
- `service.ts` реализует transactional issue/rotation, absolute seven-day TTL,
  exact scope revalidation, replay key, revocation by token/Access/key version и
  advisory-lock concurrency serialization.
- `cookies.ts` задаёт host-only `HttpOnly`, `SameSite=Lax`, `/`, bounded
  `Expires/Max-Age`, `Secure` в production-like и fail-closed insecure override.
