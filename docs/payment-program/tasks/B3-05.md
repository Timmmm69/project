## Цель

Добавить отсутствующие backend producers для session, return, pending, terminal и paid_without_access без расширения privacy payload.

## Источники требований

- `docs/payment-program/sources/payment-ux-contract-v1.md`

## В scope

- Реализовать только цель и критерии этой карточки.
- Сохранить backend truth, idempotency, transaction и privacy invariants.

## Вне scope

- Реализация соседних карточек без отдельного claim.

- Card-data UI, embedded bank form, автоматические возвраты и другие запрещённые MVP-функции.


## Критерии приёмки

- [x] События создаются только после соответствующего commit/truth decision.
- [x] Browser CTA/return не создаёт payment confirmation.
- [x] Payload проходит forbidden-data scan.
- [x] Analytics failure не откатывает бизнес-транзакцию.

## Evidence

- 6 новых event schemas в `src/lib/analytics/schemas.ts`: `payment_session_created`, `payment_pending`, `payment_failed`, `payment_cancelled`, `payment_expired`, `payment_return_viewed`. Все используют bounded enums и opaque hashes, запрещают email/signature/raw данные.
- Producers в `src/lib/commercial/commercial-service.ts`:
  - `ensurePaymentSessionCreatedAnalytics` + `ensurePaymentPendingAnalytics` — после attempt creation commit.
  - `ensurePaymentTerminalAnalytics` — после notification processing (FAILED/CANCELLED/EXPIRED).
  - `ensurePaymentReturnViewedAnalytics` (exported) — UX-only, вызывается из status route при `paymentReturn` query param.
- `src/app/api/commercial/orders/[publicId]/status/route.ts` — `payment_return_viewed` при browser return (`paymentReturn=1` или `paymentReturn=paymentCancelled=1`).
- Все события после commit; `safelyWriteAnalyticsEvent` гарантирует, что ошибка analytics не откатывает transaction. `skipDuplicates` предотвращает duplicate/callback replay events.
- Browser CTA/return не создаёт `payment_confirmed` — только `payment_return_viewed` (UX only, не proof).
- 503 tests PASS (4 новых в analytics.test.ts: schemas closed, PII-free, forbidden-key rejection, terminal analytics).
- Typecheck/lint clean.
