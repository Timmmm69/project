## Цель

После verified authority возвращать безопасное действие для существующего состояния и запрещать ненужную повторную покупку.

## Критерии приёмки

- [x] Verified Order boundary находит pending Order без token rotation или нового
  Order и возвращает только `WAIT_FOR_PAYMENT` + safe public order reference.
- [x] Unused Access, active Attempt и readable Result возвращают соответственно
  `START_TEST`, `RESUME_TEST` и `VIEW_RESULT` через server decision table.
- [x] Completed Attempt/Result блокирует repurchase.
- [x] Ambiguous/inconsistent state даёт `RECOVERY_SUPPORT_REQUIRED`, а не
  произвольный record или новую покупку.
- [x] Public projection не возвращает internal entity IDs, ответы или scoring
  data; из Order state разрешён только opaque public reference.
