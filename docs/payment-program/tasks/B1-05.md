## Цель

После verified authority возвращать безопасное действие для существующего состояния и запрещать ненужную повторную покупку.

## Источники требований

## В scope

- Реализовать только цель и критерии этой карточки.
- Сохранить backend truth, idempotency, transaction и privacy invariants.
- Обновить board, evidence и handoff вместе с изменением.

## Вне scope

- Реализация соседних карточек без отдельного claim.
- Production activation или изменение gate verdict.
- Card-data UI, embedded bank form, автоматические возвраты и другие запрещённые MVP-функции.


## Критерии приёмки

- [ ] Pending Order восстанавливается без token rotation или нового Order.
- [ ] Unused Access, active Attempt и readable Result возвращают правильное безопасное действие.
- [ ] Completed Attempt/Result блокирует repurchase.
- [ ] Ambiguous/inconsistent state даёт support, а не произвольный record.
- [ ] Resolver не возвращает чувствительные entity IDs, ответы или scoring data.

- [ ] `pnpm test` плюс targeted unit/integration tests.
- [ ] Релевантный migration/transaction/concurrency smoke.
