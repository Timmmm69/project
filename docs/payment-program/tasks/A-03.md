## Цель

Сверить каждую строку backend gap matrix с актуальным HEAD и заменить исторические статусы текущими evidence-backed статусами.

## Источники требований

- `docs/payment-program/sources/payment-core-audit-2026-07-18.md`

## В scope

- Реализовать только цель и критерии этой карточки.
- Сохранить backend truth, idempotency, transaction и privacy invariants.
- Обновить board, evidence и handoff вместе с изменением.

## Вне scope

- Реализация соседних карточек без отдельного claim.
- Production activation или изменение gate verdict.
- Card-data UI, embedded bank form, автоматические возвраты и другие запрещённые MVP-функции.


## Критерии приёмки

- [ ] Все 35 audit IDs проверены на актуальном SHA.
- [ ] Для каждого ID указаны текущие файлы/тесты и один статус.
- [ ] `IMPLEMENTED` требования превращены в regression invariants, а не удалены.
- [ ] Все `NEEDS_REVALIDATION` карточки переведены в обоснованный следующий статус.
- [ ] Ни один merchant-blocked пункт не закрыт mock/sandbox assumption.

## Обязательные проверки

- [ ] Проверка ссылок/путей и source hierarchy.
- [ ] Поиск orphan/duplicate requirements и противоречий.
- [ ] Кодовые проверки не обязательны, если код не менялся; это явно записывается в evidence.

## Evidence

- Ссылки на изменённые файлы/коммиты.
- Вывод обязательных проверок.
- Runtime/design/external evidence согласно карточке.
- Отдельный `reviews/A-03.md` перед `DONE`.

## Handoff

Следующее точное действие: Выполнить read-only аудит актуального HEAD и обновить board/cards одним документационным изменением.

Нерешённые вопросы должны быть перечислены здесь и в `docs/payment-program/handoff.md`; молчаливые архитектурные, финансовые, security или scope решения запрещены.
