## Цель

Отобразить полный набор terminal/transient/recovery states без ложного успеха.

## Источники требований

- `docs/payment-program/sources/payment-ux-contract-v1.md`
- `docs/payment-program/sources/payment-core-audit-2026-07-18.md`

Audit/traceability IDs: `STA-01`, `STA-02`, `ACC-02`, `STA-06`, `STA-07`, `UI-01`.

## В scope

- Реализовать только цель и критерии этой карточки.
- Сохранить backend truth, idempotency, transaction и privacy invariants.
- Обновить board, evidence и handoff вместе с изменением.

## Вне scope

- Реализация соседних карточек без отдельного claim.
- Production activation или изменение gate verdict.
- Card-data UI, embedded bank form, автоматические возвраты и другие запрещённые MVP-функции.


## Критерии приёмки

- [ ] Есть pending, paid, failed, cancelled, expired, unknown и paid_without_access.
- [ ] Есть Existing Order/Access/Result и recovery presentations.
- [ ] Browser return не показывает paid до backend confirmation.
- [ ] Support отображает только public reference и безопасные данные.
- [ ] Allowed CTA соответствует state и не предлагает запрещённую повторную оплату.

## Обязательные проверки

- [ ] `pnpm lint`.
- [ ] `pnpm typecheck`.
- [ ] `pnpm test`.
- [ ] Релевантные Playwright/browser scenarios и ручная visual check.
