# Module: Admin Tests

## Цель

Преподаватель может войти в админку, создать тест, настроить его, сохранить черновик, проверить перед публикацией, опубликовать или скрыть.

## Scope

- Admin auth.
- Test CRUD.
- Статусы `draft`, `published`, `hidden`, `archived`.
- Publish check.
- Поля теста из Final MVP Spec v2.

## Валидация публикации

Публикация запрещена, если нет названия, цены, времени, срока доступа, вопросов, правильных ответов, тем, баллов или есть некорректные типы вопросов.

Если включена шкала ЦЭ/ЦТ, должна быть выбрана шкала и `max_raw_score` теста должен совпадать со шкалой.
